Après le flash

1

Configuration WiFi

ESPHome Web propose la configuration WiFi automatiquement (Improv Serial). Sinon, connectez-vous au réseau frangipool-XXXX et ouvrez 192.168.4.1 dans votre navigateur.

2

Adoption ESPHome / HA

Une fois sur le réseau, ESPHome Dashboard ou Home Assistant détecte le device par mDNS. Cliquez Adopt : la clé API et le mot de passe OTA sont générés et poussés automatiquement.

3

Mises à jour automatiques

Le firmware vérifie les nouvelles versions sur cette page. Une carte Mise à jour disponible apparaît dans Home Assistant. Un clic installe la mise à jour via OTA.

Sécurité — Avant l'adoption, l'API est accessible sans chiffrement (fenêtre de quelques minutes, identique aux devices commerciaux type Shelly). Une fois adopté, credentials uniques par appareil.

Sondes de température

Deux sondes Dallas sont connectées sur le bus 1-Wire (GPIO23). L'ESP les détecte automatiquement par index — aucune adresse à configurer. Par défaut, l'index 0 alimente Température Local (ambiance locale) et l'index 1 alimente Température Canalisation (tuyau retour).

Deux entités diagnostics indiquent en permanence l'assignation active : Sonde Température Local et Sonde Température Canalisation affichent chacune « Sonde 0 » ou « Sonde 1 ».

Si les sondes sont physiquement inversées, appelez l'action frangipool_swap_dallas_probes depuis Home Assistant (Developer Tools → Actions) pour échanger leurs affectations sans retoucher ni recompiler le firmware. Les entités diagnostics se mettent à jour immédiatement et l'assignation est persistée après reboot.

La Température Piscine est une valeur échantillonnée : elle n'est mise à jour que lorsque la pompe tourne depuis au moins le délai de mesure (réglable, défaut 20 min), afin d'éviter de capturer la température de l'eau stagnante dans les tuyaux.

Filtration autonome

L'ESP calcule lui-même les horaires de filtration en fonction de la température de la piscine. La pompe démarre et s'arrête sans aucune action de Home Assistant. HA reste utile pour la supervision et les notifications, mais son absence n'interrompt pas la filtration.

Modes

Off
Pompe arrêtée. Le mode antigel reste actif indépendamment.
Hiver
Durée fixe si T < 10 °C (défaut 3 h), sinon T ÷ diviseur (défaut 3).
Courbe
Durée calculée selon une courbe adaptée à la température, modulée par le coefficient.
Auto
Bascule automatiquement entre Courbe et Hiver selon la température (seuil 16 °C avec hystérésis).

Deux cycles par jour

La durée journalière est répartie en deux plages : une le matin, une le soir. L'heure pivot définit le milieu de la pause entre les deux cycles. Les paramètres pivot et pause sont dédiés par sous-mode (Courbe / Hiver).

Antigel

Indépendant du planning. Si la Température Canalisation passe sous la consigne antigel (défaut 0 °C, réglable), la pompe démarre immédiatement quel que soit le mode ou l'heure. Un hystérésis de 1 °C évite les cyclages rapides. Une notification Home Assistant est envoyée à l'activation et à la désactivation.

Mode forcé

Trois boutons permettent de forcer la pompe pendant une durée fixe (2 h, 6 h, 24 h), prioritaires sur tout — y compris le mode Off. À expiration, retour automatique à la planification.

Calibration pH

Le module pH applique une calibration two-points : pH = slope × V + intercept, recalculés à chaque calibration. Cible : sonde Gravity pH Meter v2.0 (pH 7 ≈ 2.5 V, pH 4 ≈ 1.65 V).

Matériel nécessaire

Tampon pH 7.00 · Tampon pH 4.00 · Eau claire pour le rinçage.

Important — Coupez la pompe avant de démarrer la calibration.

Procédure (~6 min 20 s)

Tampon pH 7.00 Plonger la sonde dans le tampon pH 7.00. Attendre quelques secondes.
Démarrer Dans Home Assistant, presser le bouton Démarrer calibration pH. Notification de confirmation.
Stabilisation pH 7 — 190 s Le firmware capture 3 lectures espacées de 5 s. Vérifie que le spread reste sous 50 mV (sinon rejet).
Rinçage puis tampon pH 4.00 Notification : "V_pH7 capturé. Rincer la sonde et plonger dans le tampon pH 4.00".
Stabilisation pH 4 — 190 s Même procédure. Notification finale : "Calibration pH réussie. Pente=X.XXX, intercept=X.XXX".

Clé API — Après le flash v0.2, Home Assistant verra le device comme unavailable. Supprimez l'intégration ESPHome dans HA et ré-adoptez. Les unique_id sont conservés — vos dashboards restent fonctionnels.

Renommer le device dans Home Assistant

Par défaut, name_add_mac_suffix: true donne au device un nom unique frangipool-XXXX (XXXX = 4 derniers octets du MAC). Les entity IDs HA prennent la forme sensor.frangipool_xxxx_*.

Pour revenir à des IDs courts (sensor.frangipool_*), renommez le device dans HA :

  1. Paramètres → Appareils & Services → ESPHome → cliquez sur le device frangipool-XXXX
  2. Icône crayon → changez le nom en frangipool → Enregistrer
  3. HA régénère automatiquement tous les entity IDs.
Le dashboard Lovelace homeassistant/dashboard/frangipool.yaml utilise le préfixe frangipool_* — il fonctionne directement après ce renommage.

Migration depuis un self-compiler v1.x

Si vous compiliez depuis les sources avec un secrets.yaml local, les !secret wifi_ssid, !secret api_encryption_key ont été supprimés de packages/base.yaml. Pour conserver vos credentials custom, ajoutez-les dans le bloc substitutions: de votre preset local — ils prennent priorité sur les packages.
